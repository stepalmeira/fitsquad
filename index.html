Objetivos SMART e Canvas

SMART é uma metodologia usada para definir metas claras, estruturadas e alcançáveis, baseada em cinco critérios essenciais.

Um Canvas de projeto (ou Project Model Canvas) é uma ferramenta visual de planejamento que resume todas as informações essenciais de um projeto em uma única página

Termo de Abertura

O Termo de Abertura do Projeto (TAP) é o documento oficial que autoriza a existência de um projeto e dá ao gerente de projeto a autoridade para usar os recursos da empresa nas atividades.
